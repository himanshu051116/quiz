# dear, us. ♡

A responsive, four-page couples quiz for iPhone Safari and desktop.

Open `index.html` to begin. The playful password is `i love you` (front-end-only, not secure access control).

Pages: cover, password entry, eleven questions, answers. On the final question, "No" dodges and a reaction photo appears for under two seconds.

Source photos are in `assets/`. This is a static site intended for Vercel Git deployments.
